🛠️ Manual Remote Desktop Agent Setup

⚠️ npm Installation Issue Detected

The automatic installation failed because npm is not in your system PATH. Here's how to fix it manually:

🔧 Option 1: Fix npm PATH (Recommended)

Step 1: Find your Node.js installation

Open Command Prompt and run:

where node

This will show you where Node.js is installed (usually C:\Program Files\nodejs\)

Step 2: Add npm to PATH

1. Open System Properties → Advanced → Environment Variables

2. Find "Path" in System Variables and click Edit

3. Add the Node.js folder (e.g., C:\Program Files\nodejs\)

4. Click OK and restart Command Prompt

Step 3: Test npm

npm --version

If this works, you can now run the start.bat script again!

🚀 Option 2: Manual Installation

Step 1: Navigate to your agent folder

cd C:\Users\server\Downloads\testpc

Step 2: Install dependencies manually

Try these commands one by one until one works:

"C:\Program Files\nodejs\npm.cmd" install
"C:\Program Files (x86)\nodejs\npm.cmd" install
"%APPDATA%\npm\npm.cmd" install

Step 3: Run the agent

node agent.js

🔍 Troubleshooting

Common Issues:

  • Node.js not found: Install from nodejs.org
  • npm not found: Reinstall Node.js with npm included
  • Permission errors: Run Command Prompt as Administrator
  • Path issues: Restart Command Prompt after PATH changes
